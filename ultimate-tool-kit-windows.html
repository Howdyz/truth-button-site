Frequently asked questions

Does the Ultimate Tool Kit — Windows run on Truth Button's servers?

No. Every tool in the kit — starting with HexStrike AI — runs entirely on your own computer. Truth Button never runs it, proxies it, or sees anything it does; this page only links to a download and explains how to run it safely.

Do I need to install Python or open a terminal?

No. The Windows build is a single self-contained .exe with everything bundled in. Download it and double-click it — that's the entire setup, no terminal and no separate installs.

Is it exactly the same as the Linux version?

Nearly. A handful of binary-exploitation endpoints built on pwntools can't run on native Windows at all — a real OS limitation, not a bug — and return a normal error instead of working. Every other tool integration works the same as Linux, provided the underlying CLI tool is installed on your Windows PATH.

No. Using HexStrike AI, or any tool in this kit, against projectsilverbeam.com or its backend is explicitly prohibited. Only use these tools on systems you own or are explicitly authorized to test.
