Frequently asked questions

What image size does Facebook actually want?

1200×630 pixels, a 1.91:1 ratio — this is also what LinkedIn, X/Twitter, Reddit, and Slack use for their link preview cards, so one crop covers all of them.

Why does my photo look badly cropped when I share it?

Most photos aren't already the 1.91:1 (or other) ratio a platform expects. The platform center-crops it to fit automatically, which often cuts off exactly the part you wanted visible. Cropping it yourself first, to the exact target ratio, fixes this.

Does this upload my photo anywhere?

A file you choose is read locally and never leaves your device. A URL you paste is fetched directly by your browser from wherever it's hosted, same as opening it in a new tab — that request is visible to that image's host, not to this site. Either way, the crop and export happen entirely locally.

Does this work on mobile?

Yes — uploading a photo or pasting a URL both work fine on mobile browsers, unlike an earlier version of this tool that relied on desktop-only screen capture.

Why did loading my image URL fail?

Some image hosts block cross-origin access, which stops a browser from reading the image's pixel data even though it can display it. If pasting a URL fails, download the file and use "Choose a Photo" instead — that always works regardless of the source.
