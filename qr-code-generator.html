Frequently asked questions

How do I make a QR code for free?

Type or paste a URL, phone number, or any text into the QR Code Generator, and it renders instantly as you type. Click Download PNG to save it.

Does this upload what I type anywhere?

No — the QR code itself is generated entirely in your browser using a local, self-hosted encoder. The one exception is the optional trackable-link toggle, which requires free sign-in and sends the destination URL to our server to create the tracked short link.

What's error correction level for?

It controls how much of the code can be damaged, dirty, or obscured (e.g. by a logo overlay) and still scan correctly. Higher levels are more resistant but produce a denser code. Medium is a good default for most uses.

Is this free?

Yes, completely free, no account or install required. The optional trackable-link version is also free, but requires signing in.

Can I see or delete my trackable links?

Yes — once signed in, turning on the trackable-link toggle reveals a "My Trackable Links" list with every link you've created, its click count, and a delete button. Deleting one breaks that QR code's destination immediately.

Being straight about this: the QR code is generated entirely in your browser using a local copy of a standard open-source encoder — nothing you type is ever sent anywhere. The one exception is the optional "trackable landing page" toggle, which requires free sign-in and sends the destination URL to our server. Very long text needs a larger/denser code; if generation fails, try shortening the text or lowering the error correction level.
