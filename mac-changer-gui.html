What this actually is
A small, free, open Python/customtkinter app — not a hosted service. You download a couple of files, install a couple of dependencies, and run it on your own machine.

How it works

  1. 1Open the Mac_Changer GUI tab and read the disclaimer — it requires elevated privileges (pkexec on Linux, a UAC prompt on Windows) to actually change an address.
  2. 2Download the zip — one file with the script and both launchers (run.sh for Linux, run.bat for Windows) — and extract it.
  3. 3Install requirements — Linux: macchanger, policykit-1, customtkinter. Windows: Python 3 and customtkinter (PowerShell is already built in). Then run the launcher for your OS and pick your interface.

What it can do

🔀 Randomize / vendor control

Fully random MAC, random host bytes while keeping your current vendor, or a fresh random vendor entirely — one click each.

↩️ Reset to permanent

Restore the interface's original, burned-in hardware MAC. (Some NIC drivers don't fully honor this while the interface is up — a replug or driver reload fixes it.)

✏️ Custom MAC

Type or paste an exact address; the field auto-formats it as you go and validates it before applying it.

📋 Live info + activity log

See current vs. permanent MAC and vendor at a glance, plus a timestamped, color-coded log of every action and its result.

▶️🛑 Start / Kill Interface

Manual interface up/down control. Kill stays clickable even mid-operation — it aborts a stuck privileged command first (e.g. an unanswered password/UAC prompt), then forces the interface down as a recovery button if something else got it stuck.

Read this before you download anything:
  • Linux and Windows only — macOS isn't supported. Linux shells out to macchanger, ip, and pkexec; Windows drives PowerShell and the adapter's registry directly.
  • It's a separate app. You download and run it entirely on your own computer — Truth Button never runs it, proxies it, or sees anything it does.
  • Changing a MAC address requires elevated privileges — pkexec on Linux, a UAC prompt on Windows — each time; it never runs elevated the whole time.
  • Only change the MAC on interfaces you own or are authorized to manage. Some networks treat MAC spoofing as a policy violation — know your network's rules first.
  • You are solely responsible for how you use it.

Frequently asked questions

Does Mac_Changer GUI run on Truth Button's servers?

No. It's a separate desktop app you download and run entirely on your own computer. Truth Button never runs it, proxies it, or sees anything it does; this page only links to it and explains how to set it up.

How does Mac_Changer GUI work on Linux vs. Windows?

On Linux it's a friendlier point-and-click front end for GNU macchanger. On Windows there's no macchanger, so it drives PowerShell directly — setting the adapter's NetworkAddress registry override and restarting the adapter to apply it. Both are built with Python and customtkinter.

Does it work on macOS?

No. Only Linux and Windows are supported.

Does it need administrator/root access?

Yes, for the actual MAC change. The app itself never runs elevated the whole time — on Linux it requests privileges through pkexec, on Windows through a standard UAC prompt, each time you change or reset an address.
